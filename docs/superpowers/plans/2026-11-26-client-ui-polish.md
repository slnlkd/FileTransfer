# 客户端界面完善实施计划

**目标**：让远程资源管理器保持 Windows 桌面应用的导航习惯，让图片查看与标注工作区在视觉和交互上属于同一套客户端。

**实施方式**：沿用 .NET 10、WPF 和现有共享资源字典。建议按现有界面逐阶段完善，三个区域各自交付和验收。统一标题、控件反馈和状态语义，保留图片查看器的深色画布。

**当前进度**：阶段 0 按要求跳过。阶段 1 至 3 的界面修改已落地，等待手动视觉验收。Release 构建零警告、零错误，164 项冒烟检查与完整 WPF 窗口回归均已通过。

## 阶段 0 · 建立对照基线

- [ ] 截取浅色、深色的资源管理器，以及普通图片查看和标注模式。保留同一批次、长路径、长文件名和已标注一张图的样本。
- [ ] 记录 1280×720、1920×1080 和 Windows 缩放 125% 下的布局。重点记录标题栏、可操作区域、焦点和面板宽度。
- [ ] 跑 Release 构建和完整 WPF 窗口回归，记录实际结果。

## 阶段 1 · 统一窗口框架与控件反馈

涉及 `RemoteFiles.Client/MainWindow.xaml`、`Shared/ImageViewer.cs`、`Shared/Theme/Controls.xaml` 和主题资源。

- [ ] 保留主窗口现有系统标题栏，统一查看器窗口按钮的图标尺度、命中区与悬停层级。关闭按钮沿用危险色语义。
- [x] 查看器顶栏单行显示共享路径和居中的文件名，分别截断。悬停底部图片信息可看完整名称和路径，顶部区域可拖动窗口。标注卡片保留当前图片身份和时间。
- [ ] 复用现有主题资源统一工具栏图标、圆角、边框、焦点和选中反馈。按需补共享资源键，避免改写全局按钮样式。
- [ ] 验收最小化、最大化、还原、双击标题栏、拖动、全屏返回和键盘焦点。长文本与窗口按钮互不遮挡。

## 阶段 2 · 梳理资源管理器的操作层级

涉及 `Shared/RemoteBrowser.xaml`、`Shared/RemoteBrowser.xaml.cs`、`RemoteFiles.Client/MainWindow.xaml`。

- [ ] 保持左树、面包屑、详情表格的结构。强化目录导航和路径区域，降低连接设置、低频命令和业务筛选的视觉竞争。
- [x] 路径栏显示目录加载和取消入口，底部传输区显示上传、归档、下载和复制准备的进度。状态栏显示结果和下一步，蓝色突出下一未标注批次编号。
- [ ] 统一文件行、目录树和 NG 批次按钮的悬停、选中、键盘焦点反馈。保留现有排序、右键、拖放、方向键和 Enter 行为。
- [ ] 验收连续切换目录、路径溢出、右键选中、批次定位、720p 以及深浅主题。可操作项通过键盘可达。

## 阶段 3 · 收敛图片查看与标注工作区

涉及 `Shared/ImageViewer.cs`、`Shared/Annotations/AnnotationPanel.cs`、`Shared/RemoteBrowser.xaml`。

- [ ] 对齐左右面板标题起点、内边距、分隔线和按钮高度。保留图像作为主区域，窄窗口下优先检查提交按钮可达、左侧列表可折叠及右侧表单可滚动。
- [ ] 当前图片卡片保持三层信息。文件名用于识别，蓝色时间用于定位，右上角状态用于判断下一步。时间显示到秒，切图同步更新。
- [ ] 核对颜色语义。蓝色用于操作中和下一批入口，琥珀色用于未标注或待核实，绿色用于已标注，红色用于明确错误。状态同时提供文字，未知原因可以查看。
- [ ] 验收 `0 / 52` 与 `1 / 52` 仍表示实际图片计数。批次内标注一张后，NG 总览显示该批次已完成，并可跳到下一未标注批次。保留提交和撤销后关窗的操作链。
- [ ] 回归切图、缩放、全屏、备注标签、标注历史、读取失败、提交中、撤销中及状态恢复。共享控件同时验证客户端和服务端宿主。
