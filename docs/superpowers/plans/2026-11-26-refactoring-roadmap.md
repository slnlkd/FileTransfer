# 分阶段重构路线（暂缓实施）

2026-11-26：用户要求先保留重构计划，优先处理目录操作延迟和加载反馈问题。

## 基线与原则

- 规划基线为 v1.6.15、提交 9b3a5a3；后续操作优化需先验收，再开始重构。
- 用户选择完整分阶段路线，首阶段只处理测试基线和标注模块。
- 保留 .NET 10、WPF、现有交互、网络协议、数据库结构、配置和升级兼容性。
- 按职责拆分，不仅拆 partial 文件；不新增 MVVM 或依赖注入框架。
- 首轮保留共享源码链接方式，共享变动同时验证客户端和服务端。
- 各阶段独立提交和验收；重构本身不自动发版或部署。

## 阶段 0：测试基线

按导航、图片、标注、NG 进度、日志拆分窗口测试。定位真实前台焦点、悬浮及可见区域检查的不稳定原因，不能删除检查以换取通过。确定性测试连续通过三轮，必须依赖桌面的场景保留交互验收。

## 阶段 1：标注模块

从图片查看器提取 AnnotationPanel、AnnotationViewModel 和 IAnnotationClient 远程适配器。沿用现有 DTO，统一取消及重复提交保护；通过成功事件交由宿主关闭窗口和协调下一批。

保留提交后关闭、撤销当前图片全部记录、仅看已标注、备注标签追加去重、字典新增刷新和时间显示。关闭或切图后旧请求不能回写，失败保留用户输入。

## 阶段 2：资源管理器

依次提取目录导航协调器、NG 进度状态模型、查看窗口协调器、文件操作服务。明确分页、缓存、排序、请求版本、加载结束与取消边界，保留树与列表联动、关闭定位和下一批定位。

## 阶段 3：入口与构建边界

提取连接配置与客户端更新服务。正式 Oracle、NG、标注源码通过明确的版本化构建配置纳入，凭据及本机部署路径保留在本地配置。保留旧版传输程序。

## 验收

每阶段执行 Release 构建、冒烟及对应窗口测试；共享组件验证两端。重点覆盖快速导航、断线取消、普通及 DS616 路径、历史批次兼容、多节点字典、标注失败重试、主页激活、Ctrl 拖动、剪贴板、深浅主题及 720p 加载提示。
